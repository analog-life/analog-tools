Schematic Editor

使用手册

一个在浏览器里快速绘制模拟电路原理图的小工具。元件、导线、网络标签、注释与符号分析都在本地完成，不上传任何数据。

简介 界面 绘制流程 元件与属性 导线与标签 注释与公式 文档与导出 符号分析 快捷键 数据与隐私

简介

这个工具适合快速记录、讲解和分享模拟电路：从电阻、电容、MOS 管到运放、ADC/DAC 与功能块，拖放后接上导线即可。默认使用 Razavi 风格的符号模板。

工具基于开源项目 GmKing Schematic Editor（MIT 许可，原作者 RarityBrown）移植，并改为与本站一致的界面与中英文文案。

完全本地。绘图内容保存在浏览器的 localStorage 中，只有导出或复制时才会产生文件；服务器不会收到任何电路数据。

界面

  • 左侧面板：上方选择符号模板与元件，下方是属性编辑器。面板宽度可以拖动右边缘调整；窄屏时从左侧边缘的把手拉出。
  • 中间画布：顶部是文档标签与工具栏，底部状态栏会提示当前操作。滚轮或双指缩放，中键拖动或触摸拖动平移。
  • 右侧符号分析：从右边缘把手拉出，可以计算传递函数和输入/输出阻抗。
  • 页头：使用手册、Language 语言切换与深色模式切换。

绘制流程

  1. 点击工具栏的「放置元件」，或直接按 i，左侧出现元件选择器。
  2. 选择元件（例如 resistor），在画布上点击放置；继续点击可连续放置多个。按 Esc 结束。
  3. 按 w 进入导线模式，点击引脚、导线端点或网格点开始画线；每次点击增加一个拐点，点击引脚或按 Enter 结束。
  4. 按 Esc 回到选择状态，点击对象后可在左下角属性编辑器中修改名称、数值与外观。
  5. 用 r 旋转、Shift+R 水平镜像；按住 Shift 点击可以多选。

画布按 10 px 网格吸附，元件符号本身使用独立的 20 px 设计单位，因此移动与缩放不会改变符号比例。

元件与属性

选中元件后，属性编辑器会按元件类型显示可编辑项：

  • 名称与标签：修改位号（如 R1），控制是否显示标签和数值，以及标签位置。
  • 数值：电阻、电容、电感、电源等可以直接填写工程值，供符号分析使用。
  • 颜色与尺寸：符号颜色、线宽、×0.5 / ×1 / ×2 尺寸与固定/可变视图。
  • 类型专属选项：MOS 的引脚数与箭头、运放的极性、电感的抽头与同名端、DFF 的时钟边沿/置位/复位、滤波器的类型等。

颜色样本已改成圆形色片；第一个带圆环的是「默认黑色」，最后一个色片可打开系统取色器。

导线与网络标签

  • 导线有两种样式：普通信号线与宽线。按 Shift+w 可直接使用宽线。
  • 导线相交并形成连接时会自动出现节点；把导线拖到引脚附近会自动吸附。
  • 按 L 进入网络标签模式，输入名称后按 Enter，再点击导线或节点放置标签。标签用于命名网络，也会影响符号分析的网络列表。
  • 选中导线或节点后可以修改颜色、线宽、起点/终点标记和数字总线位宽。

注释与公式

按 Shift+N 或点击工具栏的注释图标，在画布上放置说明文字。注释支持纯文本与 Markdown，可在属性编辑器里切换格式、文字颜色与填充色。

公式使用 MathJax 在本地渲染：行内写作 $V_{out}$，独立公式先输入 $$ 再按 Enter，然后在公式块中填写 TeX。MathJax 已随工具本地化，不依赖 CDN。双击注释即可编辑，Esc 结束编辑。

文档与导出

  • 顶部标签栏可以新建多个原理图；+ 新建，标签上的 × 关闭，双击标签可重命名。
  • 标签栏右侧的按钮依次是：导入 JSON、从剪贴板粘贴 JSON、导出 JSON。
  • 编辑内容会自动保存在当前浏览器。关闭标签后仍可从「最近关闭」恢复（如果界面提供）。
  • 在画布上框选或按住 Shift 多选后，右键可以复制为 SVG、PNG、网表或 JSON。
  • 导出的 JSON 是备份与迁移的唯一可靠方式；清除浏览器站点数据会同时删除本地文档。

符号分析

  1. 从右侧边缘拉出「符号分析」面板。
  2. 为 Input +、Input −、Output +、Output − 选择网络；也可以点击 Pick 后在画布上选取。
  3. 点击「计算 H(s)、Zin(s)、Zout(s)」。结果会显示传递函数、输入阻抗和输出阻抗。

分析使用属性编辑器中的元件数值。开关、SPNT 等没有符号模型的元件不会参与计算。复杂电路可能需要较多计算时间。

数据与隐私

所有原理图、视图位置和界面偏好都保存在本浏览器的 localStorage 中，键名以 at- 开头，例如：

  • at-schematic-workspace：文档清单
  • at-schematic:<id>：单个原理图快照
  • at-schematic-view:<id>：缩放与平移
  • at-schematic-layout：面板宽度等布局
  • at-theme、at-lang：主题与语言

这些数据不会上传服务器，也不跨设备同步。需要长期保存或换设备时，请导出 JSON。清除站点数据会删除全部本地原理图。

User Manual

A small browser tool for sketching analog circuits. Components, wires, net labels, notes and symbolic analysis all run locally; nothing is uploaded.

Introduction

This editor is made for quickly capturing, explaining and sharing analog circuits: resistors, capacitors, MOS devices, op-amps, ADC/DAC blocks and more. Place a part, draw a wire, and you have a schematic. The default symbol template is Razavi.

It is a port of the open-source GmKing Schematic Editor (MIT, original author RarityBrown), restyled to match this site and translated into Chinese and English.

Fully local. Drawings live in your browser's localStorage. Files are only created when you export or copy; the server never receives circuit data.

Interface

  • Left panel: symbol template and part picker at the top, property editor below. Drag its right edge to resize; on narrow screens pull it out from the left edge handle.
  • Canvas: document tabs and toolbar above, status bar below. Wheel or pinch zooms; middle-drag or touch-drag pans.
  • Symbolic analysis: pull it out from the right edge handle to compute transfer functions and input/output impedance.
  • Header: User Manual, Language switch and dark-mode toggle.

Drawing

  1. Click Add Instance in the toolbar, or press i, to open the part picker.
  2. Choose a part (for example resistor) and click on the canvas. Keep clicking to place more; press Esc to stop.
  3. Press w for wire mode. Click a pin, wire end or grid point to start; each click adds a bend, and clicking a pin or pressing Enter finishes.
  4. Press Esc to return to selection, then click an object to edit its name, value and appearance in the property editor.
  5. Press r to rotate, Shift+R to mirror horizontally; Shift-click to add to the selection.

Wires and parts snap to a 10 px grid, while symbol geometry uses a separate 20 px design unit, so scaling never distorts symbols.

Parts & properties

Selecting a part reveals type-specific controls in the property editor:

  • Name and labels: reference designator (R1), label/value visibility and label position.
  • Values: resistance, capacitance, inductance and source values, also used by symbolic analysis.
  • Color and size: symbol color, stroke width, ×0.5 / ×1 / ×2 size, fixed or variable view.
  • Type options: MOS pin count and arrow, amplifier polarity, inductor taps and dots, DFF clock/set/reset, filter kind and more.

Color swatches are round. The first ringed swatch is the default black; the last chip opens the system color picker.

Wires & labels

  • Two wire styles are available: signal and wide. Shift+w starts a wide wire directly.
  • Wires that meet at a connection get a junction dot automatically, and wire ends snap to nearby pins.
  • Press L for net labels. Type a name, press Enter, then click a wire or junction. Labels name nets and feed the analysis net list.
  • Selected wires and junctions expose color, width, end markers and digital bus width.

Notes & formulas

Press Shift+N or click the note icon to place text on the canvas. Notes support plain text and Markdown, with text color and fill controls in the property editor.

Formulas are rendered locally with MathJax: inline $V_{out}$; for a display formula type $$ and press Enter, then fill in the TeX block. MathJax is bundled with the tool, not loaded from a CDN. Double-click a note to edit; Esc finishes editing.

Documents

  • The tab bar holds multiple schematics. + creates one, × closes it, and double-clicking a tab renames it.
  • The buttons at the right of the tab bar import JSON, paste JSON from the clipboard, and export JSON.
  • Edits are saved automatically in this browser. Closing a tab keeps it recoverable from recently closed documents when available.
  • Box-select or Shift-click, then right-click to copy as SVG, PNG, netlist or JSON.
  • Exported JSON is the reliable backup and transfer format. Clearing site data also deletes local documents.

Symbolic analysis

  1. Pull out the Symbolic Analysis panel from the right edge.
  2. Choose nets for Input +, Input −, Output + and Output −, or click Pick and select on the canvas.
  3. Click Compute H(s), Zin(s), Zout(s) to get the transfer function and input/output impedance.

Analysis uses the component values from the property editor. Parts without a symbolic model (switches, SPNT and similar) are ignored. Large circuits can take a while to solve.

Data & privacy

Schematics, view positions and interface preferences are stored in localStorage under keys prefixed with at-:

  • at-schematic-workspace — document list
  • at-schematic:<id> — one schematic snapshot
  • at-schematic-view:<id> — zoom and pan
  • at-schematic-layout — panel layout
  • at-theme, at-lang — theme and language

Nothing is uploaded or synced. Export JSON for long-term storage or another device. Clearing site data deletes all local schematics.
