Schematic Editor 使用手册

适用于 1.0.1-beta。先跟着示例画一张 RC 低通，再查阅进入子图、生成网表和导出图片的具体操作。

快速入门

  1. 点击中间标签栏的 + 新建原理图。将鼠标移到画布，按 I，依次搜索并放置电压源、电阻、电容和 GND。选中元件后可在属性里设置数值。需要调整朝向时，选中元件并按 R。
  2. 按 W 接线。把电压源正端接到电阻一端，电阻另一端接到电容一端。电容另一端和电压源负端接到 GND。将鼠标移到终点，在吸附预览正确时按 Enter 或双击完成。
  3. 按 L 添加标签，把电压源正端所在网络标为 VIN，把电阻与电容之间的网络标为 VOUT。按 F 让整个电路适合画布。
  4. 打开右侧分析，将输入正端设为 VIN、输出正端设为 VOUT，两个负端都选接地网络，然后计算。也可切到网表查看 SPICE 或 Spectre 文本。
  5. 在标签栏选择导出，用原理图 JSON 保存可编辑备份，用 SVG 或 PNG 保存图片。

界面与画布

  • 左侧器件库用于找器件、模板和图形，属性用于修改当前选区，图层用于整理对象。拖动面板分隔线可调整宽度。
  • 中间标签栏管理图纸和导入导出，工具栏提供绘图命令。画布下方显示当前操作提示。点击状态栏的 Log 可查看操作与错误消息。
  • 右侧从层次、分析、网表三个标签切换。窄屏可用边缘把手展开面板。工具栏部分按钮可横向滚动。
  • 滚轮或双指缩放，中键拖动画布平移，触屏可直接拖动画布。按 F 适合视图。演示模式可暂时隐藏画布网格及端子提示，便于检查图面。

元件、模板与图形

按 I 打开 Add Instance。左列选器件库，中列选条目，右列按名称、符号、属性顺序显示。可在放置前设定阻值、MOS 的 W/L 或器件模型。选 Templates 时，在右列逐个选择模板内部器件并编辑。点击放置或在搜索结果中按 Enter，再到画布确认位置。按 Esc 退出放置工具。

Shapes 中的图形也可从左侧器件库启动。用右列或放置后的属性面板设置线宽、颜色、线型、填充和箭头。图形作为绘图标记，电气连接用导线与元件引脚建立。

  • 矩形用两个对角点定位，三角形按顺序点三个顶点。
  • 圆形先点圆心，移动指针查看半径预览，再点第二点确认。放置后拖上、下、左、右控制点可变为椭圆。
  • 多边形逐个点顶点。预览显示候选点与上一点及首点的连线。点击首点、按 Enter 或使用完成按钮闭合。
  • 折线逐点添加顶点，按 Enter 或双击结束。弧形先放两端，再放曲线经过的第三点。两类开放图形均可分别设置首尾箭头的样式和大小，例如实心 ASME。

布线、网络标签和总线

用 W 绘普通导线，用 Shift+W 绘宽导线。点击引脚、已有导线或网格点开始。移动时关注吸附标记和路线预览，单击添加拐点，终点处双击或按 Enter 完成。绘制中按 Esc 可取消。

用 L 输入网络名并确认，然后在导线或连接点的吸附位置点击放置。输入和放置阶段都可按 Esc。同一图页中，名称完全相同的网络标签会连接对应导线，即使它们在画面上分开。标签严格区分大小写，例如 OUT 和 out 是两个名称。

用 OUT<7:0> 表示 8 位总线。单独使用第 3 位时，可在一条独立导线上放置 OUT<3> 标签。子图端口也可以使用总线范围，父图接线时检查位宽和位序。交叉位置的圆点表示真实电气连接。跨线桥只改变未连接交叉的显示方式。

选择、移动与快捷键

单击选择对象，也可从空白画布拖出选框。已选对象时，启动移动或复制后点击目标位置，操作会结束。空选区时，启动命令后点选或框选对象，再点击目标位置。放下后仍可继续拾取下一组对象，按 Esc 退出。

快捷键操作
M / Shift+M保持连接移动 / 仅移动所选对象，未选导线留在原处。
C复制点选或框选对象。复制子图符号会创建同一子图的新实例。
R已选器件就地旋转 90°。空选区时先点器件，再点击放置位置，可连续操作。
Ctrl+R / Shift+R分别执行 Mirror X / Mirror Y。
Delete / Shift+Delete删除 / 切换器件或导线的临时删除状态。空选区时可拾取目标，临时删除可再次切换恢复。
U / Shift+U撤销 / 重做。也可使用 Ctrl/Cmd+Z 与 Ctrl/Cmd+Shift+Z。
O打开选项。
F / Esc适合视图 / 退出当前工具或关闭弹窗。

注释与 TeX 公式

按 Shift+N，输入文本并设定字号和定位点，默认使用左下角。可在九个定位点中选择，放置、移动和复制时按该点吸附。按 Shift+Enter 输入换行，Enter 确认后到画布放置。选中注释后，在属性中修改文本、定位点、字体、颜色、大小、填充和不透明度。

一条注释可以混写中文、英文和 TeX，例如 截止频率 Cutoff \(f_c = \frac{1}{2\pi RC}\)。用 \(…\) 排版行内公式，用 \[…\] 单独排一行。SVG 和 PNG 导出会保留排版后的公式。

图层、可见性和对象顺序

在图层面板新增、命名、调整顺序和锁定图层。选好当前图层再绘制，或选中已有对象，在属性 → 图层改派。展开图层可查看其对象，并调整对象的可见性和层内显示顺序。

隐藏图层或对象用于整理视图，电路连接和网表仍按原理图内容计算。对器件或导线使用临时删除命令可以暂时将其排除出电路。需要把隐藏内容也放进图片时，在导出对话框勾选将隐藏对象包含在图像中。

创建并调用子图

  1. 打开层次，新建图页并命名。按 P 添加端口，填写区分大小写的名称，选择 Supply、Ground、Input、Output、InOut 或 Passive，并指定符号的上、下、左、右边。放置后将端口接入子图。
  2. 返回父图，通过器件库 → 层次或层次面板的 Place 放置自动生成的符号。将父图导线接到方框端子。一个子图可被多个实例引用。
  3. 按 E 后点击实例进入其子图，按 Ctrl+E 返回上一层。层次面包屑显示当前路径，Include cells 列出内部实例，Show callers 列出引用该图页的位置。

Pin list 的排序决定网表端口顺序，换边只调整符号显示位置。端口改名会更新符号和网表并保留连接。换边或删除端口后，父图导线留在原位，出现悬空的线头需要手动重接。Supply 和 Ground 是端口类型，需要跨图页共享的网络在Global nets中声明。

符号分析与网表

分析面板提供传递函数 H(s)、输入阻抗 Zin(s) 和输出阻抗 Zout(s)。分别为输入和输出选择正负端网络，也可用拾取工具在画布选网。计算使用图纸上的连接和器件参数。结果为空时，先检查端口选择、接地和分析诊断。

网表面板生成 SPICE 或 Spectre 文本，包含当前电路及其层次定义。先在选项 → 工艺选择工艺，再按需到对应器件的属性 → 器件模型设定模型。使用自定义工艺时可输入模型名，留空采用工艺默认值。

生成后可复制或下载。存在错误诊断时仍可生成和导出，建议先检查诊断并处理悬空端口、重复名称或缺失参数。点击可定位的诊断可返回对应对象。符号分析和网表生成均在浏览器运行，网表可带到外部仿真器使用。

保存、导入与导出

工作区和图纸自动保存在当前浏览器。标签栏上的导入和粘贴 JSON 都会在新标签打开文档。需要跨设备保存时，导出文件作为备份。浏览器清理网站数据会清除本地工作区。

  • 原理图 JSON用于保存当前图页。含子图的工程请选择项目 JSON以保存所有图页、端口和层次引用。
  • SVG便于矢量编辑和缩放，PNG适合直接分享。两者都按当前注释排版导出。选中对象后可从右键菜单复制选区。
  • 如果状态栏提示存储失败，先使用重试保存。遇到另一个窗口改动同一图纸时，可先导出本窗口的版本，再重新打开保存版本。

选项与显示习惯

  • 按 O 或点击齿轮打开选项。Language切换英文和简体中文。颜色模式可跟随系统或固定为亮色、暗色。偏好保存在本浏览器。
  • 默认文字字体应用于本图纸的注释和网络标签。在单个对象的属性中可覆盖字体，或恢复文档默认值。
  • 工艺决定网表默认模型。符号模板调整器件符号的绘制样式。
  • 导线交叉可显示直线交叉或跨线桥。导线角度可选正交、45 度或自由。45 度模式允许水平、垂直和 45° 线段。

本机 AI 协作

从 1.0.1-beta 源码目录运行 npm run agent:connector。在编辑器打开 AI → 交给 AI 修改 → 复制文本，把提示词交给可调用本机连接器的 Agent。若浏览器询问本地网络权限，允许当前页面访问本机连接器。配对码两分钟内可使用一次，连接后会话最长两小时。

AI 弹窗的状态区上方有分割线，“当前状态：”后的文案会随人工编辑、等待配对、已连接、暂停和离线状态更新。Agent 通过本机连接器读取结构化图纸和修订号。一次提交对应一次可撤销事务。手工修改后，基于旧修订号的写入会被拒绝，Agent 需要重新读取。绿色提示表示已连接，琥珀色提示表示暂停或离线。使用暂停、取消连接或收回编辑权管理会话。网站服务器不接收图纸。

Quick start

  1. Click + in the document tab strip. With the pointer over the canvas, press I and place a voltage source, a resistor, a capacitor and GND. Select each part to set its values in Properties. Press R with a part selected to adjust its orientation.
  2. Press W and wire the source positive terminal to the resistor, then the resistor to the capacitor. Connect the source negative terminal and the capacitor's other terminal to GND. Finish each wire with Enter or a double-click at the previewed endpoint.
  3. Press L to label the source net VIN and the resistor-capacitor junction VOUT. Press F to fit the circuit.
  4. In Analysis, select VIN and VOUT as the positive input and output, and ground as both negative terminals. Compute the result or open Netlist for SPICE and Spectre text.
  5. Use Export in the tab strip. Schematic JSON gives you an editable backup, while SVG and PNG give you images.

Workspace and canvas

The left panel contains Library, Properties and Layers. Document tabs, file actions and drawing tools are above the canvas. The status bar shows the current operation, and its Log button opens messages. The right panel contains Hierarchy, Analysis and Netlist.

Drag a panel divider to resize it. On narrow screens pull out the edge handles to reveal the panels. Scroll or pinch to zoom, and drag with the middle mouse button or use a touch drag to pan. Press F to fit. Presentation Mode hides drawing aids such as the grid and pin markers.

Parts, templates and shapes

Press I to open Add Instance. Choose a library and a cell, then check the symbol and properties on the right. Set values such as resistance or MOS W/L before placing a part. For a template, choose each internal component in the right column to set its parameters. Click Place or press Enter in the cell search, then click the canvas. Press Esc to leave placement.

  • Place a rectangle by its opposite corners and a triangle by its three vertices.
  • For a circle, click the center, then click again to set the previewed radius. Drag the four cardinal handles after placement to make an ellipse.
  • For a polygon, add vertices while the preview connects the candidate point to the previous and first vertices. Click the first point, press Enter, or use the Finish button to close it.
  • For a polyline, add vertices and finish with Enter or a double-click. For an arc, click its two ends and a third point on the curve. Both open shapes support independent arrow styles and sizes at each end.

Set stroke and fill in the available shape properties. Shapes annotate the drawing, while pins and wires define its electrical connections.

Wires, net labels and buses

Use W for a wire or Shift+W for a wide wire. Start at a pin, an existing wire or a grid point. Use the snap marker and route preview to place bends. Finish with Enter or a double-click at the endpoint. Press Esc to cancel.

Press L, enter a name, confirm it and place the label near a snapped wire or junction. Matching labels connect wires on the same sheet even when the wires are apart. Names are case-sensitive, so OUT and out are separate. Use OUT<7:0> for a bus and OUT<3> on a separate wire to use bit 3. Check the width and bit order when wiring a bus port. Dots identify electrical junctions, while hops show unconnected crossings.

Selection and shortcuts

Click an object or drag a box from blank canvas to select objects. With a selection, start a move or copy and click once to place it. With an empty selection, start the command, pick or box-select objects, then click the destination. Repeat until you press Esc.

Notes and TeX

Press Shift+N to type a note and choose its text size and one of nine anchors. The default is the lower-left corner. Shift+Enter inserts a line break, and Enter confirms the draft. Place the note at its snap point. Moving and copying use the same anchor. Edit text, font, anchor, color and fill in Properties.

Mix Chinese, English and formulas in a note. For example, type Cutoff 截止频率 \(f_c = \frac{1}{2\pi RC}\). Use \(…\) for inline math and \[…\] for a displayed formula. SVG and PNG keep the rendered formulas.

Layers and visibility

In Layers, create, rename, reorder, hide or lock layers. Draw on the active layer, or reassign selected objects in Properties → Layer. Expand a layer to view its objects and adjust their visibility and order.

Hiding is a display setting and preserves connectivity and netlist output. Temporary Delete excludes components and wires from the active circuit until restored. Select Include hidden objects in images to include hidden content in SVG or PNG exports.

Hierarchy and child sheets

  1. Choose New sheet in Hierarchy. Press P, enter a case-sensitive pin name, choose its type and select the side of the generated symbol. Place and wire each pin in the child sheet.
  2. In the parent, place the generated symbol from Library → Hierarchy or the sheet's Place button. Wire its square terminals. Multiple symbols can call the same sheet.
  3. Press E and pick a symbol to enter its sheet. Use Ctrl+E to return to its parent. The right panel shows the current path, included cells, pin list and callers.

Reorder pins in Pin list to set netlist port order. Renaming a pin preserves its connection and updates the symbol and netlist. Moving a pin to another side or deleting it leaves parent wires in place, ready for manual reconnection. Supply and Ground are pin types. Configure shared nets with Global nets.

Analysis and netlists

In Analysis, choose the positive and negative input and output nets, or pick them on the canvas. Compute the transfer function H(s) and the input and output impedances Zin(s) and Zout(s). If no result appears, check the terminal selections, ground and diagnostics.

In Netlist, choose SPICE or Spectre and copy or download the result. Set the process in Options → Process and override a device model in that component's Properties. A custom process allows typed model names. Blank overrides use the process default.

Diagnostics stay available even when the editor generates a netlist with errors. Inspect model names, disconnected ports and parameter values before using that result. Clicking a locatable diagnostic selects its object. Netlist files can be opened in an external simulator.

Save, import and export

Open tabs and drawings are stored in the current browser. Use Import for a JSON file or Paste schematic JSON for text from the clipboard. Both open a new tab. Export backups before moving to another device or clearing site storage.

  • Schematic JSON saves the current sheet. Project JSON saves all sheets, ports and hierarchy references.
  • SVG keeps vector graphics and PNG produces a shareable raster image. Use the context menu to copy a selection. Both image formats retain typeset notes.
  • Use Retry save after a storage failure. If another window edited the same schematic, export your local version before reopening the stored one.

Options

Press O or use the gear to open Options. Language switches between English and Simplified Chinese. Color mode follows the system or uses Light or Dark. Both preferences stay in this browser.

Set a document's default text font for notes and labels, override it on individual objects in Properties, choose the process and symbol template, and choose Plain or Hop for unconnected wire crossings. Wire angle offers Orthogonal, 45 Degree and Free routing.

Local AI collaboration

Run npm run agent:connector in the 1.0.1-beta source directory. Choose AI → Hand off to AI → Copy text and give the prompt to an agent that can use the local connector. Permit local network access if your browser requests it. A pairing code works once within two minutes. A paired session lasts up to two hours.

A divider separates the AI dialog's status area. The text after Current status: follows manual editing, pairing, connection, suspension, and offline states. The local connector provides a structured snapshot and a revision number. Each accepted transaction creates an Undo entry. Manual edits advance the revision and stale AI submissions are rejected. The green indicator shows a connection and amber shows suspension or an offline connector. Use Suspend, Disconnect or Reclaim editing to control the session. The website server receives no schematic data.
